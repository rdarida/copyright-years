# copyright-years

Generate dynamic copyright year ranges (e.g., 2024-2026).

## Installation

```sh
npm install copyright-years
```

## Usage

```ts
import { copyrightYears } from 'copyright-years';

copyrightYears(2024); // "2024-2026"
copyrightYears(2026); // "2026"
```
